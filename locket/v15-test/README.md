# V15 thử nghiệm bổ sung khóa V3

Bổ sung 39 khóa bằng giá trị V3; không ghi đè `storage_bucket` và `storage_bucket_video`. Giữ video 30 giây / 0,9 Mbps. Chưa kiểm thử trên iPhone.

Chỉ bật một module Locket: tắt V15 cũ trước khi bật bản thử nghiệm. Để quay lại, tắt bản thử nghiệm và bật lại V15. Hai script còn lại dùng chung đường dẫn V15.
